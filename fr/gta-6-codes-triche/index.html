Codes de triche GTA 6 : comment les débloquer et les saisir sur PS5 et Xbox

Les codes de triche font leur retour dans GTA 6, mais pas tout de suite. Il faut d’abord les débloquer, et les utiliser a un prix. Voici comment ça marche.

Auteur : Patryk Ładowski · Mis à jour : 21.11.2026 · 4 min de lecture

L'essentiel
  • Les codes ne sont disponibles qu’après avoir terminé l’histoire – chacun doit être débloqué par un défi.
  • Nombre de codes : 61 (joueur, combat, véhicules, environnement, filtres d’image).
  • Saisie : sur le téléphone du personnage, par une séquence de flèches sur la croix directionnelle.
  • Le prix à payer : utiliser un code bloque les trophées et la sauvegarde jusqu’à ce que tu quittes le jeu.

Les codes de triche existent dans GTA 6, mais ils ne fonctionnent qu’après avoir terminé l’histoire. Il y en a 61, chacun doit être débloqué par un défi distinct, et on les saisit avec les flèches sur le téléphone du personnage. Utiliser un code bloque les trophées et la sauvegarde jusqu’à ce que tu quittes le jeu.

Comment débloquer les codes de triche dans GTA 6 ?

  1. Termine l’histoire principale (dernière mission : « The End of the Road »).
  2. Ouvre le menu de progression et l’onglet des codes.
  3. Chaque code a son propre défi – par exemple, le code qui augmente le niveau de recherche se débloque en semant la police à plusieurs reprises.
  4. Une fois la condition remplie, la combinaison apparaît dans le menu.

C’est un gros changement par rapport à GTA 5, où les codes fonctionnaient dès le début du jeu.

Comment saisir un code ?

  • Ouvre le téléphone (flèche du haut).
  • Passe en mode de saisie des codes – selon GTABase, il faut maintenir L1 et appuyer sur R1 ; selon HotHardware, maintenir toutes les gâchettes et tous les boutons de tranche. Fie-toi à l’indication en jeu.
  • Saisis la séquence avec les flèches de la croix directionnelle. Les combinaisons sont identiques sur PS5 et sur Xbox.

Que perds-tu en utilisant des codes ?

  • Les trophées et succès sont bloqués jusqu’à ce que tu quittes le jeu.
  • La sauvegarde est désactivée pendant la même session.
  • Ta sauvegarde existante reste intacte – il suffit de quitter le jeu pour revenir à une partie normale.

Si tu vises le platine, fais d’abord le 100 %, et amuse-toi avec les codes seulement ensuite. Plus d’infos dans notre page trophées de GTA 6.

Questions fréquentes

Y a-t-il des codes de triche dans GTA 6 ?

Oui, GTA 6 compte 61 codes de triche. Ils ne se débloquent toutefois qu’une fois l’histoire principale terminée, et chaque code a son propre défi de déblocage.

Comment entrer un code dans GTA 6 ?

Ouvre le téléphone avec la flèche du haut, va sur l’écran des codes et saisis la séquence avec les flèches de la croix directionnelle. Les combinaisons sont les mêmes sur PS5 et Xbox Series X|S. Les sources divergent sur les boutons à maintenir enfoncés – suis l’indication affichée à l’écran.

Quel est le code argent de GTA 6 ?

Le code pour 250 000 $ est : haut, droite, bas, gauche, haut, gauche, bas, droite. Il se débloque après avoir terminé l’histoire.

Les codes de triche bloquent-ils les trophées dans GTA 6 ?

Oui. Après avoir utilisé un code, les trophées et la sauvegarde sont bloqués jusqu’à ce que tu quittes le jeu. Les codes n’abîment cependant pas ta sauvegarde existante.
